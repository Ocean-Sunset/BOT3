Prowl supports two OpenAI-compatible providers out of the box:

Groq
Free tier — fastest inference. Works with Llama, Mixtral.
1. Go to console.groq.com
2. Create API key
3. Set GROQ_API_KEY in Vercel env
OpenRouter
Multi-model gateway — Claude, GPT, Llama & more.
1. Go to openrouter.ai
2. Create API key
3. Set OPENROUTER_API_KEY in Vercel env

Rate limits: 1 minute cooldown per user, 5 second global cooldown across all servers. AI responses are ephemeral (only visible to the person who ran the command).
