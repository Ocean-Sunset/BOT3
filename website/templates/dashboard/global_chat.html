How It Works

1. Enable Global Chat and select a hub channel.

2. Select a private management channel and click Deploy Panel.

3. Use the control panel buttons to mute, block users/servers, change channels, or toggle global chat.

4. Messages in the hub channel are relayed to every linked server.
