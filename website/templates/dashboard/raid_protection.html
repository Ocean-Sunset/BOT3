Actions Explained
Kick — removes each flagged new member.
Ban — bans each flagged new member.
Lockdown Server — locks the server down: active invites are deleted and everyone (new or existing) is blocked from sending messages and joining voice. Existing members are handled with your moderation actions (kick / ban / mute) while it stays locked. Use Auto Recovery to re-open it.
Require Verification — locks the server and enables the verification panel so real members can prove they're human.

How Scoring Works

Every new member starts at 0 points. Each criterion they match adds its points. If the total reaches the threshold, the action above is applied immediately.

Example: default avatar (+2) + young account (+2) + join burst (+1) = 5. With a threshold of 3, they're kicked on arrival.
