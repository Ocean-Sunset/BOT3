- The bot token never leaves the bot server. Website -> bot actions go through
  the aiohttp HTTP bridge (cli/Ediscord/http_bridge.py) authorized with the
  BOT_HTTP_TOKEN shared secret (X-Prowl-Token header), port BOT_HTTP_PORT (24612).
- discord.py 2.7.1 Member.edit supports (nick, avatar, banner, bio) natively;
  Member.guild_avatar / Member.guild_banner read per-guild assets back.
- Alias design: guild-scoped copies of real commands via
  Command._copy_with(parent=None, binding=..., bindings={binding:binding},
  set_on_binding=False) then dup.name = alias; tree.clear_commands(guild=g)
  -> tree.add_command(dup, guild=g) -> tree.sync(guild=g); 60s polling loop,
  re-syncs only changed guilds.
- Alias validation both sides: name regex ^[a-z0-9_-]{1,32}$, max 50 aliases
  (ALIAS_MAX). Static catalog ALIAS_COMMAND_CATALOG in website/api/index.py
  must be kept in sync with actual commands in cli/components/*.py.
- PROFILE/BOT-PROFILE limits: nick <= 32 chars, bio <= 350 chars, images
  <= 10MB as base64 data URI (cap 14,000,000 chars), must start "data:image/".
- Dashboard conventions: settings keys must match between bot DEFAULTS dicts
  and website/api/index.py. Save-bar pattern: markChanged stores original[key];
  on save MUST delete original[key]; discard rebuilds from LOADED + original.
- CSS cache-busting: bump ?v=N in every template referencing an edited static
  css file. Embedded <style> blocks in templates need no bump.
- Form elements do NOT inherit font-family - always set
  font-family:'Lexend',system-ui,sans-serif explicitly. Input focus convention:
  border-color rgba(255,255,255,0.2) (white), NOT blurple. Input bg #1a1a1a.
- Master toggles on feature pages: md-toggle md-toggle-xl in the page header.
